# AI Prompt Engineering Mini Project

## 📌 Objective
To explore how different prompt styles affect AI-generated responses and improve output quality.

## 🧪 Experiments Conducted

### 1. Recursion Explanation
- Compared basic prompt vs improved prompt
- Improved prompt included real-life examples and structured explanation

### 2. Artificial Intelligence Content
- Tested general vs structured prompt
- Improved prompt generated clear, concise, and well-formatted output

### 3. Coding Task (Palindrome)
- Compared basic code generation vs structured prompt
- Improved prompt included explanation and time complexity

## 🔍 Key Observations
- Adding context improves clarity of responses  
- Structured prompts improve readability and usefulness  
- Clear instructions produce more accurate and detailed outputs

- ChatGPT  
- Prompt Engineering Techniques
